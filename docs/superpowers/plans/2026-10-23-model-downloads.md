## Shape

- **Every download is an SP4 manifest pulled by `strata pull`**, the confined downloader the CLI
  already uses (size + SHA-256 per file, redirect allowlist, resume, the store under a root). The
  server starts `strata` as a supervised child (no shell, fixed argv, closed environment, the Job)
  and reads machine-readable progress from its stdout; `strata-secure-server` still links no
  network code (`privacy_test`).
- **O4** is enforced where manifests are made (`hf_source`: host `huggingface.co`, an
  `owner/repo`, a 40-hex commit, a path ending `.gguf`; redirects only to `*.huggingface.co`,
  `*.hf.co`) and again by SP4's own rules in the child (sources and redirect patterns from the
  manifest, each hop checked).
- **Catalog** (`secure_frontend/catalog/downloads.json`, generated by
  `tools/secure/download_catalog.py` from upstream `setup.py` and Maya `maya.py`, embedded at build):
  one entry per GGUF variant. Upstream entries carry commit, size and SHA-256 per file. Maya's carry
  SHA-256 per shard at `main`; at start the server asks Hugging Face (through `strata hf-info`, the
  same confined downloader) for the commit and sizes, and refuses unless every reported SHA-256
  equals the pinned one.
- **Pasted link (O3):** `POST /v1/strata/downloads/link {"url"}` -> `strata hf-info` -> the file
  (and its split siblings), commit, sizes and SHA-256 shown; the page confirms; then the same pull.
- **Disk (O2):** free bytes of the downloads root's volume; a start needs the missing bytes + 2 GiB
  (+ the pack estimate for a Qwen model); otherwise 507 `insufficient_storage` with both figures.
- **Prepare (D7):** after a Qwen pull, `tools/secure/prepare_download.py` (run with the configured
  Python, `models.prepare_python`, an absolute path) calls upstream `tools/iq_pack.py` and
  `tools/strata_tokenizer.py` (read-only, from `models.prepare_tools`, the upstream tree) into
  `<downloads_root>/packs/<id>/`, detects the PLE shard, and writes `prepared.json`. The server
  then writes a card (`<roots.state>/cards/<id>.json`, owner-only) from the catalog facts and the
  engine settings of `models.download_engine_card` (an existing qwen card), and the launcher adds
  it at once (and at boot). GLM entries download only ("needs the GLM engine").
- **Config:** `models.downloads` (bool), `models.downloads_root` (absolute, existing owner-only
  dir), `models.prepare_python`, `models.prepare_tools`, `models.download_engine_card`.

## JSON contracts

`GET /v1/strata/downloads` (keyed; 404 unless `models.downloads`; 403 for remote clients unless
`models.control_remote`):

```json
{"object": "list",
 "disk": {"root": "C:", "free_bytes": 173946175488, "total_bytes": 511101108224},
 "active": {"id": "qwen3.8-flash-next-iq2_xs", "file": "IQ2_XS/...-00001-of-00002.gguf", "bytes": 123, "total": 456,
            "rate_bps": 98000000, "eta_s": 610} ,
 "data": [{"id": "qwen3.8-flash-next-iq2_xs", "name": "Qwen3.8-Flash-Next IQ2_XS", "source": "strata",
           "family": "qwen", "about": "2-bit i-quant ...", "repo": "ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF",
           "size_bytes": 68000000000, "files": 2, "state": "available", "bytes": 0, "total": 68000000000,
           "error": null, "needed_bytes": 70147483648, "fits": true, "runnable": true,
           "note": "after the download the pack is built (about 2 min) and a card appears in Models"}]}
```

States: `available | queued | downloading | verifying | preparing | ready | installed | failed |
cancelled` (`installed`: files done, not runnable here; `ready`: a card exists). `source`:
`strata | maya | custom`.

`POST /v1/strata/downloads/start` `{"id"}` -> 202 `{"state": "queued"}`; 404 `model_not_found`, 409
`switch_in_progress` (already queued/running), 507 `insufficient_storage`.
`POST /v1/strata/downloads/link` `{"url"}` -> 200 `{"confirm": {"id", "name", "repo", "commit",
"files": [{"path", "size", "sha256"}], "size_bytes", "needed_bytes", "fits"}}`; 400
`invalid_request` (not a Hugging Face `.gguf` link: a fixed reason), 502 `upstream_unavailable`.
`POST /v1/strata/downloads/start` `{"url", "confirm": true}` -> 202 (a custom card).
`POST /v1/strata/downloads/cancel` `{"id"}` -> 202.

`strata pull ... --progress-lines` stdout (one line each, fixed words):
`MANIFEST <name:tag> <sha256>` / `FILE <path> <size>` / `BYTES <path> <done> <total>` (at most every
250 ms) / `FINISHED <path> <result>` / `RESULT ok|<reason>`.
`strata hf-info <url>` stdout: one JSON object `{"repo","commit","files":[{"path","size","sha256"}]}`
or `ERROR <reason>`.

## Tasks

1. **hf_source + manifests** (controller): URL grammar and host rules (O4), SP4 manifest text for
   an HF file set, the catalog reader. RED/GREEN in `hf_source_test.cpp`.
2. **Catalog generator + prepare script** (worker, Python): `tools/secure/download_catalog.py`,
   `catalog/downloads.json`, `tools/secure/prepare_download.py`; pytest under `tests/` (the
   repo's pytest setup).
3. **strata CLI** (controller): `--progress-lines` on pull, `hf-info`, launcher configs
   (`models.downloads_root` as the store root).
4. **Server** (controller): config keys, `DownloadManager` (queue, child, progress, cancel, disk,
   prepare, card writing), routes, the launcher's runtime card add; e2e on the fake curl harness.
5. **Page** (worker): a Downloads section on the Models tab against the contract above.
6. **Box** (controller): numpy/regex into `.venv-dev`; the Qwen mmproj (0.9 GB) and one pasted link
   end to end; an oversized model refused for space; docs, full suite.
