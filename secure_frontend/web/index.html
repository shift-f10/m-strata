Folders

Where downloads go, and the folder Add a model opens. These settings apply when the server restarts.

Model folders

By default the server uses a model folder only when other users of this PC cannot change it, and offers to make a folder private first. With this switch on, it uses your model folders as they are and never changes their permissions: other users of this PC can read or change those model files, and the engine reads them as you. The server's own folders stay private. This setting applies when the server restarts.

Email alerts

The server can email you when a download finishes or fails, a calibration ends, a model's engine stops, or the server starts. It sends over TLS only (SSL/TLS on 465, or STARTTLS on 587), from its own mailbox. These settings apply when the server restarts.

Web search

With web search on, a model can look things up when it is not sure of a fact or the answer needs recent information, through your own SearXNG instance, and answer from what it found with the links. The searches leave this PC through that instance: what a model searches for comes from the chat. These settings apply when the server restarts.
